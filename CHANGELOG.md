# 📜 Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-08-08

### Added
- **20 lessons** in two parts:
  - Part 1 — JavaScript (00-11): hello Node, variables & types, operators & coercion, strings & template literals, arrays, objects & JSON, control flow, loops, functions, scope & closures, error handling, async JavaScript
  - Part 2 — Node runtime (12-19): modules, npm, file system, events, streams & buffers, HTTP & servers, CLI & process, capstone todo CLI
- **18 exercise + solution pairs** with built-in Malaysian checkers (no test framework needed — just run the file!)
- **`npm test`** — runs every lesson and solution to verify everything works
- **EXPECTED_OUTPUTS.md** — what each lesson should print
- **CONTRIBUTING.md** — beginner-friendly contribution guidelines
- **helpers/math.js** — demo module used by Lesson 12

### Notes
- Requires **Node.js 24 LTS or newer**
- Zero dependencies — everything runs with plain `node`
- Malaysian English voice throughout (the repo's soul!)
